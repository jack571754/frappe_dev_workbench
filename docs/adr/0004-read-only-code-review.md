# 使用本机 Claude Code 进行单向代码审查

研发工作台的代码审查板块由管理者手动选择提交，调用当前电脑 WSL/Docker 隔离环境中的 Claude Code，读取固定版本代码并生成报告。复核结论保存在工作台，管理者线下反馈，不修改源码、不向 Codeup 发布评论、任务或合并操作。

用户于 2026-10-21 确认此用途使用 Claude Code。与 ADR-0003 的提交摘要不同，代码审查明确需要将代码交由 CLI 配置的模型服务处理；该用途例外不改变摘要的数据发送范围。模型认证由本人完成，工作台不保存 Claude 登录凭证。

第一版采用白名单本机 Git 仓库读取固定 SHA 的对象，避免依赖尚未验证的 Codeup 新版 diff 接口。未配置本机路径或版本缺失时明确失败，管理者配置后重试；不退回读取当前工作树。快照使用只读容器挂载，CLI 仅开放读取和搜索，系统级隔离及完整认证预检不通过时禁止领取真实任务。

代价是电脑与执行器必须在线，且本机需要准备相应仓库版本。任务的执行状态与人工复核状态独立，部分覆盖和未发现问题明确区分，不把模型结论当作修复证明或成员评分。

2026-10-22 修正：用户使用 Windows 本机 Claude Code CLI 配置的第三方模型。执行器仅复用该 CLI settings.json 中模型地址、凭证和模型映射白名单，不使用官方账号登录或 OAuth，也不加载本机开发钩子、插件或写入权限。配置文件仅引用路径，凭证不复制到工作台配置；模型连接失败时不静默回退到官方服务。

2026-10-22 引擎接入：用户指定阿里 alibaba/open-code-review，默认执行引擎改为官方 OpenCodeReview CLI 1.13.2。沿用只读容器、固定版本材料、私有复核和第三方模型配置；通过 OCR JSON 中的逐文件覆盖凭据和评论转换到统一报告。原始 Git 提交和用户开发目录不变，OCR 操作过滤后的无远端临时 Git 快照，不提供仓库发布凭证或评论接口。审查规则版本升级，避免把此前 Claude 的报告误当作新引擎审查结果；旧报告仍保留。
