# 中文部署文档目录

本目录汇总当前项目的中文部署文档，按“先方案、后实战”的顺序阅读。

## 文档清单

1. `01-服务器生产部署方案（单机版）.md`
   - 目标：从零搭建标准生产环境（HTTPS、MariaDB、Redis、ERPNext）。
   - 适用：新环境初始化、正式上线前准备。

2. `02-内网IP部署与发布排障总结.md`
   - 目标：记录内网 IP 访问部署、私有应用发布、镜像化上线与故障排查实战。
   - 适用：现网维护、版本发布、应急排障。

3. `03-静态资源错乱排障手册.md`
   - 目标：定位并修复发布后样式错乱、静态资源 404、assets 哈希漂移问题。
   - 适用：`migrate` 成功但页面样式异常的线上环境。

4. `04-ERPNext-CSS-404-排查与修复（容器资源不同步）.md`
   - 目标：针对 `bench build` 后 HTML 与 `frontend` 静态文件不同步的问题，提供可直接执行的排查和修复步骤。
   - 适用：CSS 404、前后端资源哈希不一致、怀疑 `assets` 卷或 `public/dist` 漂移的环境。

5. `PSP用户导入与发版构建避坑指南.md`
   - 目标：记录 PSP 用户导入弹窗重构、单人/批量双模式录入、Docker 构建缓存避坑（CACHE_BUST）与完整发版流程 SOP。
   - 适用：功能维护、镜像打包卡缓存排障、完整上线发版指导。


## 建议阅读顺序

1. 先读 `01-服务器生产部署方案（单机版）.md` 完成基线部署。
2. 再读 `02-内网IP部署与发布排障总结.md` 落地发布与运维流程。
3. 出现静态资源异常时，查阅 `03-静态资源错乱排障手册.md`。
4. 若已确认是容器资源不同步或 `bench build` 后开始报错，再查阅 `04-ERPNext-CSS-404-排查与修复（容器资源不同步）.md`。
5. 开发与发版过程中，参阅 `PSP用户导入与发版构建避坑指南.md` 进行功能扩展与打 Tag 部署。

## 命名规范（后续新增）

- 文件名格式：`序号-中文主题.md`
- 推荐序号：`03` 起递增（例如：`03-回滚与备份手册.md`）
- 每份文档开头应注明：适用场景、前置条件、回滚方式。
